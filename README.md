# Descriptive Statistics Calculator

A C++ application for descriptive statistical analysis. The project started as a simple calculator and gradually evolved to include different tools for analyzing individual data and grouped data.

## Features

* Measures of central tendency
* Measures of dispersion
* Frequency tables
* Data grouped into intervals
* Statistical calculations for grouped data
* Bar charts

## Project Structure

The code is organized into modules according to their responsibilities:

* **Functions:** processes individual data and performs statistical calculations.
* **Intervals:** processes grouped data and performs calculations using intervals.
* **Common:** contains functionality shared by both modules.
* **Main:** handles the menu and coordinates the program's execution.

## Concepts

During the development of this project, I applied:

* Clean Code
* DRY (Don't Repeat Yourself)
* SRP (Single Responsibility Principle)
* Modular organization
* Code readability and maintainability

The project was also an opportunity to learn how to identify responsibilities and reorganize code as the application grows.
